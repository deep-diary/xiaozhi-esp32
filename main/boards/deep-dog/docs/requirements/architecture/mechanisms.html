EXT_PIN 互斥模式

引出脚 A/B（默认 38/48）成对模式；IO 与 LED 不会同时 AVAILABLE

  Mode["DEEP_DOG_EXT_PIN_MODE"]
  Mode --> NONE["NONE 前端壳"]
  Mode --> CAN["CAN TWAI"]
  Mode --> UART["UART"]
  Mode --> RS485["RS485 占位"]
  Mode --> PWM["PWM 舵机/云台"]
  Mode --> IO["IO 纯 GPIO"]
  Mode --> AD["AD 占位"]
  Mode --> LED["LED WS2812"]

ENABLE 依赖钳位

  CE --> ME["MOTOR_ENABLE"]
  ME --> DE["DOG_ENABLE"]
  ME --> AE["ARM_ENABLE 占位"]
  PWM["EXT_PIN=PWM"] --> SE["SERVO_ENABLE"]
  PWM --> GE["GIMBAL_ENABLE"]
  SE -.->|互斥 云台优先| GE

实现 TU 整文件 #if DEEP_DOG_*_ENABLE；调用侧同步门控。改开关后普通重编即可。
