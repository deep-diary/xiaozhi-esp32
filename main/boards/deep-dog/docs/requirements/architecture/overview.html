硬原则

能力可裁剪

  • EXT_PIN_MODE + DEEP_DOG_*_ENABLE
  • 实现 TU 整文件 #if 门控
  • info/device.capabilities 反映前端入口

控制汇聚 MCP

  • 语音 / WS-MCP / MQTT mcp_call → 同一 self.*
  • status / retain 仍走 MQTT 遥测面

输入与业务解耦

  • Touch / Handle Hub 只产事件快照
  • 语义在 Apps（dog / servo / log / pairing）

运控垂直 · 视觉并行

  • Dog → Leg → Trajectory? → Motor → CAN
  • Camera → Hub → Face（永驻）∥ Stream（按需）
