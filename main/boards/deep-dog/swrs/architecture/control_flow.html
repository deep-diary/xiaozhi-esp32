Boot 控制流

控制流 硬件 控制面 
flowchart TD
  Start(["板级构造 DeepDog"]) --> I2C["I2C0 共享总线"]

  Reg --> Net["StartNetwork"]

  WaitIP --> Imu["IMU 初始化"]
  Imu --> Defer{"DEFER_HEAVY?"}
  Defer -->|否| Heavy["启动 MQTT / WS-MCP / Face / Hub"]
  Defer -->|是| Act["等待激活"] --> Heavy
  Heavy --> Ready(["就绪"])

MCP 调用时序

语音 / WS-MCP / MQTT mcp_call → InvokeToolSync → Domain
sequenceDiagram
  participant Voice as 语音或客户端
  participant WS as WS-MCP / MQTT
  participant MCP as McpServer
  participant Dom as DogControl / DeepMotor
  participant Bus as CAN

  Voice->>WS: tools/call 或 mcp_call
  WS->>MCP: ParseMessage / InvokeToolSync
  MCP->>Dom: self.chassis.go_forward 等
  Dom->>Bus: 关节目标经 Motor 发帧
  Bus-->>Dom: 反馈帧 processCanFrame
  Dom-->>MCP: 工具结果
  MCP-->>WS: JSON-RPC 响应
  WS-->>Voice: 成功/失败

手柄 → 动作时序

BT 或 PC MQTT 桥注入快照；App 解释后调 Domain
sequenceDiagram
  participant Src as BT / MQTT handle/input
  participant Hub as HandleEventHub
  participant Disp as HandleAppDispatcher
  participant App as HandleAppDog
  participant Dog as DogControl

  Src->>Hub: 轴/按键快照
  Hub->>Disp: 分发事件
  Disp->>App: keymap 匹配
  App->>Dog: 前进/转向/站立等
  Dog-->>App: 状态可选回写
Touch 路径同构：TouchEventHub → Dispatcher → TouchAppDog / Servo。
