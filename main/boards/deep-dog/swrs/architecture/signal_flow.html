MQTT cmd → status 时序

sequenceDiagram
  participant FE as 前端 / 脚本
  participant EMQX as EMQX
  participant Mod as *_mqtt 适配层
  participant Dom as Domain API / MCP
  participant Out as status retain

  FE->>EMQX: publish …/cmd
  EMQX->>Mod: 订阅回调
  Mod->>Dom: 域 API 或 mcp_call
  Dom-->>Mod: 结果
  Mod->>EMQX: publish …/status
  EMQX->>FE: 订阅推送
  Note over Out: device/info 等 retain 供晚到客户端
