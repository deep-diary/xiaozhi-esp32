# 单腿控制模块 (Leg)

## 功能概述

**机器狗单腿**抽象：一条腿 3 个关节（髋侧摆、髋前后、膝），对应 3 个无刷电机，由 `../motor` 驱动。本模块负责单腿的**步态相位**、**站立/卧倒**以及**迈一步**的目标位置计算，不直接发 CAN，只输出关节目标位置给 motor 层。

---

## 目录与文件

- `leg_control.h`：腿类型枚举、接口声明、参数（步数、限位等）
- `leg_control.cc`：实现

---

## 机械与关节（简要）

每条腿三个关节在步态中的分工：

| 关节 | 说明 | 步态中作用 |
|------|------|------------|
| 髋侧摆 (Hip AA) | 外侧电机 | 站立时维持足端间距，可做小幅摆动 |
| 髋前后 (Hip FE) | 中间电机 | 前进/后退的主要动力：摆动相前摆，支撑相后推 |
| 膝 (Knee FE) | 远端电机 | 摆动相屈曲抬脚，支撑相伸展承重 |

控制上下限 = 站立位置 ± 半活动范围，并夹在物理限位内。半活动范围建议见 `../dog/README.md` 中表格。

---

## 属性（设计）

- 腿类型：`fl` / `fr` / `rl` / `rr`（前左、前右、后左、后右）
- 三个电机的 ID 数组、站立位置、当前位置
- 三个电机的控制上下限（弧度）
- 前进一步的总步数、当前步数（用于正弦分相）

---

## 方法（接口设计）

| 方法 | 说明 |
|------|------|
| 设置电机 ID / 上下限 | 配置本腿 3 个电机与关节限位 |
| 设置站立位置 | 保存当前关节角为站立位（狗已站立时调用） |
| 回到零位（卧倒） | 三关节置 0，不依赖外部传入 |
| 回到站立位 | 驱动到已保存的站立位置 |
| 设置步数 | 基于总步数 + 当前步数，计算正弦相位并得到各关节偏移 |
| 向前迈一步 | 当前步数 +1，目标位置 = 站立位置 + 正弦偏移 |
| 向后迈一步 | 同上，相位方向相反 |
| 腿初始化 / 关闭使能 | 对 3 个电机做使能/失能 |

实际控制位置需在关节限位内做夹紧（clamp）。

---

## 与上下层关系

- **上层**：`dog` 调用 leg 的迈一步/站立/卧倒，并协调 4 条腿的步序。
- **下层**：leg 通过 `motor` 层（DeepMotor）设置目标位置/使能，motor 再经 `can` 发指令。
- **轨迹**：站立/卧倒过程若需平滑，可由 `trajectory` 做点对点规划，leg 按点设置目标。

---

## MCP 控制指令（单腿，可选）

- 初始化、站立、卧倒、向前迈一步、向后迈一步（单腿调试用，可选实现）。
