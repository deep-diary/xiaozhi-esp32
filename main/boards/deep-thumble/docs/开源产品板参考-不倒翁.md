# 开源产品板参考：可控倒向不倒翁

**归属产品**：Deep Thumble（不倒翁）  
**当前实现枢纽**：[`deep-dog`](../../deep-dog/)（功能先在此迭代，再以可配置方式移植到本板）  
**文档定位**：从本仓库已有开源板型中，筛选「产品级 / 桌面摆件 / 玩具」形态，作为不倒翁产品设计的参考清单（不含开发板，不含本仓库自建板）。

| 项 | 说明 |
|----|------|
| 排除板型 | `deep-diary`、`deep-dog`、`deep-thumble`（自建） |
| 筛选标准 | 成品/开模外壳倾向；偏桌面摆件或玩具；对「可控倒向」有动作、姿态、外形或量产化参考价值 |
| 不纳入 | 面包板、Korvo、立创实战派、各类纯 DevKit / EV Board |

---

## 1. 背景与研发路径

本板（`deep-thumble`）最初定位为**不倒翁产品**开发目录；后续 `deep-dog` 功能持续丰富（运动、IMU、MQTT、视觉、舵机、电源策略等），实际开发重心已集中在 `deep-dog`。

约定路径：

1. **功能先在 `deep-dog` 落地**，用 `config.h` / `board_features.h` 做剖面裁剪（见 [`FEATURE_FLAGS.md`](../../deep-dog/FEATURE_FLAGS.md)）。
2. **稳定后通过可配置/模块移植**，落到 `deep-thumble` 作为不倒翁量产形态。
3. 本文档服务**产品形态与竞品/开源参考**，不替代 `deep-dog` 的模块实现文档。

与不倒翁能力的大致映射：

| 你要解决的问题 | 优先参考板型（见下文 Top 10） |
|----------------|------------------------------|
| 倾斜 / 摇摆 / 回正动作 | otto-robot → electron-bot → esp-hi |
| 倾角 / 倒向感知（IMU） | **esp-spot** |
| 圆脸桌宠外观与表情 | movecall-moji / esp-vocat |
| 桌面摆件结构与灯效 | atoms3r-echo-pyramid / sp-…-muma |
| 量产电源与休眠 | xingzhi-metal-1.54-wifi |

## 2. Top 10 可参考板型

路径均相对仓库根目录：`main/boards/<name>/`。

### 2.1 `otto-robot` — Otto 人形机器人

**最贴近「可控倒向」的动作参考。**

| 维度 | 内容 |
|------|------|
| 形态 | 开源人形玩具机器人 + 小智语音 |
| 能力 | 多舵机：走/转/跳；**摇摆、弯曲身体、摇腿、上下运动**等 |
| 软件 | MCP 统一动作接口 `self.otto.action`（speed / amount / direction） |
| 其它 | 电源管理、小程序控制、立创开源硬件 |

→ 重点抄：`swing` / `bend` 一类「倾斜—回正」动作编排与 MCP 参数设计。

---

### 2.2 `electron-bot` — electronBot 桌面机器人

**桌面摆件机器人标杆。**

| 维度 | 内容 |
|------|------|
| 形态 | 稚晖君风格桌面级机器人（EVE 灵感） |
| 能力 | 6 自由度：双臂 pitch/roll、**身体旋转**、头部俯仰 |
| 软件 | 语音 + 表情屏 + MCP 动作 + 局域网 WebSocket 调试 + AI 自编程舵机序列 |
| 其它 | 固件内舵机安全角度裁剪 |

→ 重点抄：身体旋转、组合动作、桌面产品交互闭环与安全限位。

---

### 2.3 `esp-hi` — ESP-HI 低成本舵机狗

**低成本「能动玩具」参考。**

| 维度 | 内容 |
|------|------|
| 形态 | ESP32-C3 超低成本 AI 对话机器人 |
| 能力 | 0.96" 彩屏表情 + 舵机机器狗数十种动作 |
| 软件 | WebUI 控身体；资源占用优化（唤醒词 + 外设同机） |

→ 重点抄：小 MCU 上塞进运动 + 语音 + 表情的取舍。

---

### 2.4 `esp-sparkbot` — SparkBot

**轮式玩具机器人 + 灯光表演（亦是 deep-dog 硬件同源参考）。**

| 维度 | 内容 |
|------|------|
| 形态 | 官方 SparkBot：摄像头、圆屏、底盘 UART |
| 能力 | MCP：前进/后退/左右转、跳舞、灯光模式 |

→ 重点抄：运动类 MCP 封装方式（不倒翁可用偏心轮/飞轮/舵机替代底盘语义）。

---

### 2.5 `esp-spot` — ESP-Spot 语音盒

**姿态感知最相关（带 IMU）。**

| 维度 | 内容 |
|------|------|
| 形态 | 智能语音交互盒子，无屏，RGB + 双按键 |
| 能力 | **内置 IMU**；电池供电；S3 / C5 版本 |

→ 重点抄：倾斜检测、回正判断、倒向感知——「可控倒向」几乎刚需。本板 `sensor/` 已有 IMU 占位，可对标其用法。

---

### 2.6 `movecall-moji-esp32s3` / `movecall-moji2-esp32c5` — Moji 表情桌宠

**典型桌面表情摆件形态。**

| 维度 | 内容 |
|------|------|
| 形态 | 圆形 240×240 脸屏 + ES8311 + LED |
| 其它 | Moji2 升至 ESP32-C5；立创开源 |

→ 重点抄：圆脸表情 UI、桌宠外观与结构；不倒翁「脸部」可对标。

---

### 2.7 `esp-vocat` — 喵伴

**圆形桌宠 + 表情动画。**

| 维度 | 内容 |
|------|------|
| 形态 | 1.85" QSPI 圆形触摸屏 |
| 能力 | 双麦、离线唤醒、声源定位；Emote 表情动画风格 |

→ 重点抄：圆形屏 + 表情动画，做「有性格的不倒翁脸」。

---

### 2.8 `atoms3r-echo-pyramid` — Echo Pyramid 金字塔

**纯桌面摆件造型。**

| 维度 | 内容 |
|------|------|
| 形态 | AtomS3R + 金字塔底座，圆屏（GC9A01） |
| 能力 | 底座供电；STM32 协同 RGB 灯带、功放等 |

→ 重点抄：异形外壳、灯效氛围、桌面摆件供电与结构分工。

---

### 2.9 `sp-esp32-s3-1.54-muma` — 小木马

**玩具外形成品。**

| 维度 | 内容 |
|------|------|
| 形态 | 「可爱小木马」造型 |
| 能力 | 1.54" 240×240、天气时钟、SD 视频、AI 对话；触摸唤醒/打断；可充电 |

→ 重点抄：玩具化外壳与儿童向功能打包；不倒翁的「角色化」产品包装。

---

### 2.10 `xingzhi-metal-1.54-wifi` — 星智铝合金量产款

**量产电源 / 休眠 / 交互参考（运动能力弱，偏产品化）。**

| 维度 | 内容 |
|------|------|
| 形态 | 铝合金成品：1.54" LCD + CST816 触摸 |
| 能力 | 电源键开关机、浅睡/深睡、电量与充电；触摸音量/唤醒/配网 |

→ 重点抄：产品级电源与休眠策略（摆件需「放桌上待机很久」）。同类可看 `xingzhi-abs-2.0`（ABS + 4G 双模）。

## 4. 移植到 deep-thumble 时的建议取舍

结合「功能在 deep-dog 做、再配置移植」的路径，建议分层对照：

| 层次 | 在 deep-dog 先做什么 | 移植到 thumble 时注意 |
|------|----------------------|------------------------|
| 姿态 | IMU 上报与倾角语义（已有 MQTT/模块文档） | 与本板 `sensor/` 对齐；倒向控制闭环以 thumble 机械为准 |
| 运动 | 舵机 / 偏心执行器 MCP（可参考 otto / electron / sparkbot 封装） | 勿直接绑死四足 `dog/`；用产品剖面开关裁剪 |
| 表情 / 灯效 | LED、表情资源 | 本板已有 `led/`；圆脸 UI 可对标 moji / vocat |
| 电源休眠 | 电量、浅睡/深睡 | 对标 xingzhi；摆件场景优先「长待机」 |
| 视觉 / MQTT | deep-dog 已较完整 | 按 thumble 硬件能力裁剪，保持同一套 capabilities 语义便于前端复用 |

功能开关权威说明见：[`deep-dog/FEATURE_FLAGS.md`](../../deep-dog/FEATURE_FLAGS.md)。  
本板需求总入口见：[SWRS.md](../SWRS.md)。
